# 标注工具发布验证

验证日期：2026-10-25。本报告仅描述标注工具，不包含模型性能或临床验证结论。

## 本次验证

- Python 3.9 标准库环境：10 项测试通过，包括 SQLite 保存/修订、并发版本递增、完整导入前校验、保留本机记录、旧单线字段迁移、多标注者重复记录/等级平票处理、路径与本机 Origin/Host 防护、HTTP 导出与回读。
- Node 内置测试：4 项通过，直接执行真实前端的保存逻辑，覆盖正常保存、保存过程中继续绘线不被旧响应覆盖、保存失败时保留修改且不无限重试、未结束笔画时阻止离开/导出。Node 仅用于开发测试，不是标注者运行依赖。
- Python 编译、JavaScript 语法与 JSON schema 语法检查通过。
- Edge 中用合成图实际绘制上/下颌线、添加严重度点、填写整体等级/质量/标注者并保存，刷新后回读成功。真实浏览器保存的完整 JSON 通过发布的 Draft 2020-12 schema 校验。
- 桌面布局本次截图无横向溢出；预览图仅合成图。

## 边界

- Windows 和 Linux 启动脚本尚未在对应操作系统现场验证；核心实现只依赖 Python 标准库。
- 自动化扩展的本地文件选择权限限制了浏览器导入文件选择步骤；导入 HTTP API 已验证，不能将该限制说成浏览器界面导入已端到端验证。
- TIFF 等非通用浏览器格式可能需要负责人统一转换；无法解析尺寸的文件会跳过并提示，不以 1×1 假尺寸保存标注。
- 暂无多标签页同病例冲突合并和多人在线协作，使用者应每人一份数据库、同一病例只在一个标签页修改。
- 无自动模型推理、临床诊断或训练框架导出适配器。正式大规模标注仍需专业 SOP、试标和一致性复核。
