# 全景片骨嵴线与吸收等级标注规范（工作草案）

> 本文件是工具的数据定义建议。项目由经过统一培训的口腔医学生完成影像初标，标注可作为研究中的影像诊断依据和模型监督证据；正式分发前仍需由项目口腔/牙周专业负责人确认等级定义、可评估标准和分歧处理规则。

## 标注单位

- 影像（case）：一张已经筛选为可评估的全景片，含自动生成的病例整体等级和人工记录。
- 骨嵴线：上颌、下颌各可含多个可见边缘折线段。仅画影像支持的部分；断裂或重叠区域可留空，不连猜测线。
- 严重度位置点：通用影像坐标点，不隐含牙号、牙面或临床受累牙。
- 解释样本：少量高质量人工例子；将观察、证据、解释、不确定性分别记录。

## 标注者与证据等级

本项目的主要标注者为经过统一培训的口腔医学生。其标注可以用于：

- 全景片病例的研究影像分层和诊断依据记录；
- 骨嵴线、局部严重度点和病例级等级的模型监督；
- VLM 输入的结构化证据和解释样本。

为避免把个人判断直接当成无误差真值，正式数据应保留标注者 ID、影像质量、置信度和复核状态，并执行：

1. 共同试标和 SOP 培训；
2. 一部分影像的双人独立标注；
3. 分歧病例的专业人员复核或仲裁；
4. 训练、验证和最终报告分别记录原始学生标注与仲裁版本。

学生标注是研究级影像诊断依据，不自动等同于临床最终诊断；临床使用仍需执业口腔/牙周医生结合病史、口内检查和其他影像资料确认。

## 培训示例

项目培训中使用两类参考图：

- **正常/未见明显吸收示例**：影像已经筛选为可评估，牙槽嵴整体连续，未见明确局部骨吸收。绘制可见的上、下颌骨嵴线；没有严重度点时系统自动生成 `none` 并标记完成。
- **牙槽骨吸收示例**：可见牙槽嵴下降、不规则或多区域骨支持减少。需要绘制骨嵴线，并在最有代表性的异常位置添加严重度点、颌别、等级和置信度。

培训截图中的颜色约定为：绿色线＝上颌骨嵴线，蓝色线＝下颌骨嵴线，黄色虚线＝公开数据集牙区辅助 polygon，编号圆点＝局部严重度位置证据。黄色辅助 polygon 不等于人工骨嵴线；它只能帮助定位牙区和理解公开标签。

## 等级建议

工具提供 `none / mild / moderate / severe / uncertain / ungradable`。病例整体等级不手动输入，而是根据严重度点自动计算：`severe > moderate > mild > none`；若只有 `uncertain` 或 `ungradable` 点，则保留相应不确定状态；若已经绘制骨嵴线但没有严重度点，则自动判为 `none`。未开始绘制的空白病例才保持“待开始”。项目负责人需在正式标注前写清每级基于何种影像征象、测量基准、允许的年龄/牙位处理、植体/缺失牙规则，以及整体级别如何从局部级别汇总。本工具不内置并不声称某一个定义是公认临床标准。

## 绘线提示

1. 使用原始影像显示，不对线条坐标做裁切/缩放空间变换。
2. 沿连续可见的牙槽嵴顶点勾线；正常病例也必须绘制骨嵴线，因为没有严重度点并不等于没有结构监督。
3. 影像边缘或重叠导致定位不确定时停止该段，在备注说明；不要在牙根/牙周膜边界与骨嵴之间混淆。
4. 上下颌由分别着色的线标识；严重度点另行选择颌别。
5. 点击错误的严重度点可在右侧列表删除；病例等级会随点位变化自动更新。“清除当前线”会清除所选工具对应的整条线（浏览模式下清除两条线），使用前确认当前工具。

## 建议的双标与仲裁

- 所有标注者先共同试标一批病例，讨论边界案例并修订 SOP。
- 预先抽样做双标；保留原始独立版本，不覆盖。
- 报告病例级序数等级的 weighted kappa / 类别混淆；骨嵴线报告对齐后的平均/中位点距及容差内比例；位置点先做匹配策略，再报告定位误差。
- 由资深口腔/牙周专家仲裁，不以多数票替代专家判断。
- 对无法判断区域用 `uncertain` / `ungradable` 和质量字段显式表示；不要默认为健康/无吸收。

## 数据解释与下游限制

坐标以归一化影像坐标存储，可无损换算到像素空间，但不具备毫米尺度。全景片有投照几何与放大误差；骨嵴线本身不含 CEJ/根尖参考，不能单独计算可信的根长比例。严重度点标签是人工标签，不自动转换成牙位诊断。VLM 只应围绕结构化标注给出简洁证据说明与不确定性。
